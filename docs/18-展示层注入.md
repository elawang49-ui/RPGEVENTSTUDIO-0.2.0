# 展示层注入（Presenter Injection）

事件运行时只依赖一组展示协议，不依赖具体 UI。游戏可以把插件默认对话框换成自己的叙事 UI，
同一份事件资源不需要改动。

## 展示协议

注入对象需要实现以下方法（`close_all` / `fade_to` / `clear_fade` 可选）：

| 方法 | 说明 |
| --- | --- |
| `show_text(speaker: String, text: String, auto_advance: float)` | 显示一段文字 |
| `is_text_finished() -> bool` | 玩家已确认 / 文字已结束 |
| `show_choices(prompt: String, options: Array)` | 显示选项 |
| `get_choice() -> int` | 已选中的 0 起下标；未选择返回 `-1` |
| `close_all()` | 关闭当前 UI、清空回调与输入状态 |
| `fade_to(alpha: float, duration: float) -> Tween` | 可选，淡入淡出 |

没实现 `fade_to` 时，`fade` 指令会被跳过，不会假装已经淡入淡出。

## 注入 / 恢复

```gdscript
var runtime := get_node_or_null("/root/RPGEventStudio")
runtime.set_presenter(my_presenter)          # 注入游戏自己的 UI
runtime.restore_default_presenter()          # 恢复插件默认 UI
runtime.is_using_default_presenter()         # 当前是否默认 UI
```

- 默认展示层（`DialoguePresenter`）始终保留；注入后它会被隐藏并停止处理输入。
- 注入对象如果是尚未入树的 `Node`，`set_presenter()` 会把它挂到运行时下。
- 事件运行过程中替换展示层会**取消正在运行的事件**，并先对旧展示层调用 `close_all()`。
- 旧事件收尾时只关闭「它自己使用的」展示层，不会误关新展示层。
- 运行时退出时会取消所有事件，并关闭当前展示层与默认展示层。

## 兼容性

- 事件资源格式不变；`show_text` / `show_choices` / `if` / `@@self.choice` 等指令不变。
- 没有注入时行为与以前完全一致。
- 展示协议是「单活动显示」模型：同一时刻应由一个事件占用对话框。
