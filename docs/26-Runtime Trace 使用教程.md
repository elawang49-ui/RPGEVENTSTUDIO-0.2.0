# 26 · 如何使用 Runtime Trace 排查剧情问题

> 适用人群：策划、内容创作者。不需要懂 GDScript、JSON 或 trace_id。
> 所有截图与按钮名称以当前版本为准；本教程只写实际存在的功能。

## 一、打开运行追踪

1. 在 Godot 编辑器里**运行游戏**（F5）。
2. 游戏里按 **F2**，打开状态调试面板。
3. 点面板右上角的 **「运行追踪」** 按钮，进入追踪视图。

追踪视图从上到下是：

| 区域 | 内容 |
| --- | --- |
| 工具栏 | 记录追踪开关、事件 ID/名称过滤、状态标识过滤、结果过滤（全部/完成/取消/失败）、清空、导出 JSON、详情方式 |
| 时间线 | 按时间排列的“剧情发生了什么”，每一行都是自然语言描述 |
| 详情区 | 选中一行后，显示这行的自然语言解释；把「详情方式」切到「原始 JSON」可看技术字段 |

要点：

- 状态和条件会显示**状态库里的中文名**，不是内部标识。
- 事件名、变量名、节点 ID 等你自己起的内容保持原样。
- 追踪只记录本次运行；退出游戏后记录清空。

## 二、七个常见问题怎么查

### 案例一：NPC 没有触发

在时间线里找这几行：

- 「**剧情未触发：xxx**」——当前没有符合条件的事件页。详情区会列出每一页的
  触发方式与条件检查结果，重点看“未选中”的页缺了什么。
- 「**剧情被忽略：xxx（同一事件正在执行）**」——这个事件还在执行，重复触发被丢弃。
- 「**剧情被忽略：xxx（执行策略不允许）**」——事件页设置了“只执行一次/变化时执行”，
  这次不满足重复策略。

详情区的「触发来源」会告诉你这次触发来自哪里（交互对象 / 触发区域 / 自动事件 / 关卡图节点）。

### 案例二：NPC 选错了事件页

找「**事件页选择**」这一组记录：

- 「选中」的那行就是实际执行的事件页；
- 其余页会显示「未选中」，展开看它的条件检查：哪个条件不满足、预期是什么、实际是什么。

### 案例三：条件分歧走错了

找「**条件检查：xxx**」这一行，详情区显示：

- 预期：你要的值
- 实际：运行时的真实值
- 结果：条件满足 / 条件不满足
- 执行：进入「是」分支 / 进入「否」分支

### 案例四：状态没有正确写入

找「**游戏状态变化：xxx：旧值 → 新值**」：

- 如果压根没有这一行，说明对应指令没执行（先查案例一/三）。
- 如果有这行但新值不对，详情区的「来自指令」告诉你哪条指令写的。

### 案例五：关卡图没有继续推进

找这几类行：

- 「**关卡图 xxx · 节点 xxx · 进入/退出**」——节点有没有被执行到。
- 「**关卡图分支：xxx 的「true」→ xxx**」——实际走了哪条线。
- 「**剧情线汇合：xxx AND 1/2**」——等待全部(AND)需要 2 条输入，当前只有 1 条；
  详情区会提示「还需 1 条输入才会触发」。

从编辑器启动游戏时，**双击**图节点/条件/分支记录，编辑器会定位到对应关卡图节点。

### 案例六：剧情中途取消

找「**剧情结束：trace #n · 取消/失败**」：

- 完成 = 正常走完；
- 取消 = 场景切换或主动取消；
- 失败 = 某条指令执行出错（例如调用了不存在的公共事件）。

已知限制：等待超时没有独立的“超时”结果；引擎级崩溃无法被记录（详情区不会伪造结果）。

### 案例七：回到出错位置 / 交给程序员

- **双击事件记录**：编辑器直接打开对应事件。
- **双击图节点/条件记录**：编辑器定位到关卡图节点（图未打开时自动加载）。
- **导出 JSON**：点「导出 JSON」，文件写到 `user://rpg_event_studio_trace.json`，
  发给程序员或 AI 工具分析。

> 定位功能需要从编辑器启动游戏；把游戏单独打包运行时，双击只在面板里查看，不会打开编辑器。

## 三、必须知道的三件事

1. **只记录内存**：默认容量 2000 条，超出后丢弃最旧记录；不支持剧情回放。
2. **开发者可关闭**：环境变量 `RPG_EVENT_STUDIO_TRACE=0` 关闭记录，
   `RPG_EVENT_STUDIO_TRACE_CAPACITY` 调整容量；正式导出版默认关闭。
3. **专业模式还在**：详情方式切到「原始 JSON」即可查看全部技术字段，两种视图共用同一份数据。

## 四、读不懂时的兜底

如果记录不足以判断原因，详情区不会替你下结论。此时优先：

1. 再跑一遍复现，扩大容量后再看；
2. 检查事件页条件与触发方式是否和场景里挂的组件一致；
3. 把导出的 JSON 交给会看技术字段的人。
