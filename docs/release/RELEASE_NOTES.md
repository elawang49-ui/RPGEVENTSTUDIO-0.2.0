# RPGEVENTSTUDIO 0.2.0-rc1 发布说明草案

这是从 `9368e33`（Batch 1 + Batch 2）建立的独立发布候选版本。推荐先以 `0.2.0-rc1` 交第三方 Godot 4.7.2 项目试接入；收集平台与自定义适配器验收反馈后再标记 0.2.0 正式版。

## 修复

- Story 顺序式与嵌套式选项块支持整体删除、复制、移动和撤销；命令树深拷贝隔离容器，外部事件/媒体资源继续保持引用。
- 剪切撤销后粘贴不会重复插入同一个资源。页面增删、条件字段、触发方式、重复策略可撤销。资源操作保留真实实例，面板关闭后撤销仍安全。
- Inspector/Story 共享事件数据并同步刷新。Graph 参数 UndoRedo 保留原基线修复。Map 隐藏时停止扫描，隐藏的主题预览停止渲染；状态库和角色取色合并写盘，弹窗与字体选择器归属面板生命周期。
- StateStore 批处理支持嵌套和通知重入；事件采用会话隔离，取消/失败不再提交半途状态。once 成功后消耗，嵌套与父级共享提交/回滚，冲突明确失败。
- 共用 Presenter 的展示指令串行取得所有权；非展示事件不会误关正在使用的 UI。等待中的宿主、角色、镜头或 Presenter 释放时安全取消。
- 暂停冻结事件、等待与默认展示层；场景退出取消旧事件、停止旧图，清理锁与引用。
- Graph 对被忽略/拒绝的事件及时放行，正常等待按实例匹配；停止后的协程保留到安全退出。
- 空文本自动推进、选项重复点击、批量注册搜索大小写问题修复。
- 插件首次安装持久注册 Autoload，禁用识别路径/UID，关闭编辑器不会误卸载。
- 增加 fresh-clone 导入前置、完整日志、安装包验证与 GitHub Actions 配置。空白安装的失败退出码得到故障注入实证。

## 兼容与限制

事件中途的开关对宿主不可见，这是用户确认过的行为调整；存档和 Resource 格式不变。需要中途通信时使用既有 EventBus/适配器协议；需要永久写入时由宿主明确调用共享状态 API。

本次没有重做视觉系统、资源 schema、指令扩展方向或核心事件资源模型。没有合并 main，没有触碰主题功能分支，没有向远程仓库发布。

仍保留的限制：Graph 多出边继续按既有顺序调度（不承诺任意分支的真正并行执行）；外部副作用不属于状态事务；自定义 Presenter 要遵守宿主暂停规则；尚未在 Windows/Linux 实机完成 GUI 验收。CI 文件已提供，本地不能替代远程 Actions 执行结果。基线已有的 Godot 退出期 resources-in-use 诊断规则未增加，完整日志保留，未宣称引擎退出零诊断。

详细通过数量、宿主测试契约差异及提交记录见随附质量报告。
