## 1. 第一批 A/C 缺口修复

### A · 专业视图时间线保留原始 ID / 枚举

审计发现 `7970cbf` 的“原始 JSON”模式只切换了事件结果列和详情 JSON，
时间线摘要、条件分支、阶段值、图端口、汇合模式仍然是中文。

修复：

- 新增 `_raw_summary()`：专业视图下事件 ID、状态键、阶段值、`true/false`、
  `out`、`and/or`、命令类型、调用路径、节点 ID 全部使用原始值。
- `_result_text()` 在专业视图下对 `selected/matched/fired` 也输出 `true/false`。
- 顶部“最近结束”在专业视图下显示原始事件 ID，不显示显示名。
- 自然语言视图行为不变。

回归：`tests/trace_ui_test.gd` 新增 7 项专业/自然视图对照检查，共 21 项。

### C · 超长正文滚动

审计发现 1152×648 下长正文被从行中间裁掉，`scroll_active` 始终为 `false`。

修复：

- 正文高度仍夹在 `[text_min, panel_max]`，但窗口过矮时优先保证面板不出屏。
- 内容超过 `panel_max` 时按需开启 `scroll_active`，短文本不显示滚动条。
- 新文本显示时重置滚动位置；滚动条可鼠标滚轮操作。
- 新增 `tests/dialogue_layout_test.gd`（11 项）：长文本滚动、短文本不滚动、
  对话框/选项面板底边不出屏、选项过多时内部滚动。

## 2. 第二批 E-H

### E · 关卡总控图

- 工具栏改为 `HFlowContainer`：窄窗口按钮换行，不再把主屏最小宽度撑到 1371px。
- 新增「适配」按钮：打开图时自动缩放到全部节点/分组框，也可手动点。
- 节点卡片优先显示用户自定义 `title`，无标题时才显示类型名；新增类型色条与类型文字。
- 摘要支持自动换行，节点/摘要带完整 tooltip。
- 小地图缩小到 160×110、透明度 0.65，减少遮挡。
- 画布/参数栏 split 随窗口宽度调整，画布至少 560px。

### F · 地图事件编辑器

- 地图事件面板按可用宽度切换列：
  - 窄 dock：只显示「事件」一列（⚠/● + 名称），触发方式/位置/事件放进详情与 tooltip；
  - ≥360px：显示「事件 / 触发」两列，列头可见。
- 状态用 ⚠ 标记，失效引用不再只靠颜色。
- 详情限制 5 行，层级/路径/完整状态进 tooltip，窄 dock 不再撑破面板。
- 小窗口右侧 dock 可能被编辑器挤出屏幕，因此主屏新增「地图事件」标签页作为全宽入口；
  选中对象仍会同步两个面板。
- 新增 `scene_root_override`，让截图/测试可在非编辑器环境注入示例场景。

### G · UI 主题编辑器

- 预览与参数改为左右分栏；可用宽度 <720px 时自动上下排列。
- 预览高度固定 480px，SubViewport 跟随容器尺寸，避免对话框预览落到可视区外。
- 参数区增加「分区跳转」下拉（对话框/文字/选项/动画/提示）与分区包裹。
- 路径/状态标签超长省略，不再把整页撑宽。
- 修复编辑器标签页初次构建时 SubViewport 只有 2×2 的问题。

### H · 其他界面

- F1 按键设置面板按窗口收缩（最大 680×560，窗口更小时不顶出屏幕）。
- 剧情工作台/剧情资源审计页外包滚动容器，避免其 1400×1900 的最小尺寸把
  TabContainer 撑出窗口。
- 地图事件主屏标签页保证 1152×648 下仍可访问地图事件列表。
