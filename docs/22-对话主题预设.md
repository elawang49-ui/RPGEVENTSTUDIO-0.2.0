## 2. 架构

```text
DialoguePresenter（通用：布局 / 输入 / 打字机 / 分页 / 选项状态）
├─ DialoguePanelDecor     面板底、渐变、底纹、双层框、角花、胶带、刀锋
├─ DialogueNameplate      铭牌形状、阴影、文字、附标、左栏分隔线
├─ ThemeChoiceRow         选项行形状 + 内部 Button（保留旧输入接口）
└─ DialoguePortraitSlot   立绘裁切/比例/框体；Overlay 画边框角标
        ↑
RpgEventStudioTheme（纯数据）
        ↑
DialogueThemePresets（工厂 + 元信息；每次 create 新实例）
```

没有为 6 套主题各写一个 Presenter。布局结构由主题字段组合：

- `panel_shape`：`rect` / `notched` / `slant` / `cinema`
- `frame_style`：`plain` / `double` / `ornament` / `stitch` / `blade` / `hairline` / `armor`
- `choice_panel_style` + `choice_style`：`panel` / `bare` × `rect` / `pill` / `skew` / `note` / `bar` / `notch` / `wing`
- `nameplate_style`：`inline` / `float` / `capsule` / `parallelogram` / `wood` / `blood` / `column`
- `portrait_style`：`square` / `rounded` / `capsule` / `circle` / `octagon` / `polaroid` / `angular` / `blood`

CSS 的 `clip-path`、`skew`、`repeating-linear-gradient`、虚线、硬阴影、
双层边框、旋转胶带等，分别落到：

- `Control._draw()` 多边形 / `draw_style_box` / `draw_polyline` / `draw_dashed_line`
- `dialogue_panel_decor.gd` 的逐行渐变与底纹
- `ThemeChoiceRow` 的形状绘制
- `portrait_mask.gdshader` 的圆窗/八角/切角遮罩
- 独立 overlay 层保证立绘纹理不会盖住边框

## 3. 主题数据

`RpgEventStudioTheme` 保留原有字段，新增字段全部有兼容默认值。分组：

| 分组 | 内容 |
| --- | --- |
| 预设 | `preset_id`、标题、标签、说明、系列、`style_version` |
| 对话框 | 底色、边框、圆角、阴影、锚点、内边距、轮廓、缺口/斜切、装饰边框、角饰、渐变、底纹、硬阴影、主/副强调色、刀锋、装甲条 |
| 文字 | 字体路径/字族、正文/说话人/提示字号、行距、描边、打字速度 |
| 选项 | 选项面板、形状、斜切角度、选中位移、普通/选中/悬停颜色、标记、阴影、边框 |
| 铭牌 | 样式、底色/边框/圆角、文字/强调色、偏移、旋转、角标、附标、阴影、内边距、左栏宽度/分隔线 |
| 立绘框 | 开关、样式、左右、尺寸/宽高比、底色、边框、内边距、内框、阴影、旋转、角标、间距、色调、占位 |
| 动画/提示 | 原有字段不变 |

关键兼容点：

- `preset_id == ""` 且新增字段为默认值时，`uses_decor_base()` 返回 false，
  继续走旧 `StyleBoxFlat` 路径，旧 `.tres` 外观完全不变。
- `choice_panel_style == "panel"` 时选项仍使用旧面板和 `make_choice_style`
  颜色，`tests/run.gd` 的旧断言继续有效。
- 事件资源序列化格式、EventRunner/GraphRunner、BBCode、分页、打字机、自动播放
  均未改语义。主题只影响 `DialoguePresenter` 的视觉组件。

## 4. 预设管理

编辑器主屏 →「UI 主题」：

1. 顶部「主题预设」下拉：插件默认外观 + 6 套预设。
2. 切换预设立即重建预览；下方展示标题、说明、4 色板。
3. 参数区修改实时作用于预览；「立绘框」开关在预设行右侧。
4. 「保存主题」写 `res://ui/rpgeventstudio_theme.tres`，保留 `preset_id`。
5. 「重新加载」从磁盘恢复。
6. 「恢复默认」回到**当前预设的工厂值**；旧主题（`preset_id` 为空）回到插件默认外观。

预设是工厂，不是共享单例：

```gdscript
var a := DialogueThemePresets.create("sacred")
var b := DialogueThemePresets.create("biscuit")
a.choice_selected_bg = Color.MAGENTA
# b 不受影响；再次 create("sacred") 也是出厂值
```

切换预设会得到新实例，因此上一套未保存的临时修改不会污染下一套。

## 5. Portrait Slot

### 运行时接口

```gdscript
# StudioRuntime
RPGEventStudio.set_dialogue_portrait(texture)
RPGEventStudio.clear_dialogue_portrait()

# 或直接对默认 Presenter
presenter.set_dialogue_portrait(texture)
presenter.clear_dialogue_portrait()
```

- 只接收 `Texture2D`，不读写角色/表情资源，不向 `EventCommand` 加临时字段。
- `portrait_enabled` 由主题控制；主题开启但没有纹理时，默认隐藏整个框体
  （`portrait_show_placeholder` 可保留占位）。
- 立绘框固定高度、宽度 = 高度 × `portrait_aspect`，`TextureRect` 用
  `STRETCH_KEEP_ASPECT_COVERED` 裁切，不会被长文本拉高。
- 立绘在正文左侧/右侧（`portrait_side`），中间由 `_speaker_spacer` 留出
  `portrait_gap`；窄窗口（< 620px 或面板 < 480px）自动让位，正文优先。
- 角色立绘、表情差分、立绘切换属于独立的角色资源系统，另行规划。

### 框体样式

- 圣堂：方框 + 内金线 + 星芒角标。
- 蜜桃：圆角 + 粉色硬阴影 + 角标。
- 机能：斜切 + 青色边 + 黄色硬阴影 + 闪电角标。
- 电影：细白框 + 无角标。
- 手账：拍立得白边 + 胶带 + 轻微旋转。
- 猩红：斜切缺口 + 猩红硬投影 + 十字。

## 6. 编辑器预览

- 预览使用真实 `DialoguePresenter`，不是另写一套假 UI。
- `SubViewport` 以固定虚拟分辨率（默认 960×600，可切 1280×820 / 1152×648）
  离屏渲染，再由 `AspectRatioContainer` 等比缩放，避免编辑器面板尺寸改变布局。
- 预览背景只属于编辑器，用于看清边框/阴影层次，不参与运行时。
- 宽窗口左右分栏；低高度窗口可点「预览」切换为全高预览。

## 9. 已知限制

- 按需求没有实现纯白神谕、浮生水墨两套；注册表只含 6 套。
- 立绘只有显示接口与示例纹理；角色立绘/表情资源管理是后续独立系统。
- 选项文字单行显示，超长文本使用省略号 + tooltip；不做逐项富文本换行。
- 编辑器预览为等比缩小的整屏虚拟分辨率，字体渲染与真实 1:1 窗口会有像素差异；
  运行时截图为准。
- 系统字体依赖 macOS/Windows 的 CJK 字体回退；可通过 `font_path` 指定项目字体。
- HTML 原型里的星芒旋转、光标浮动等纯装饰动画未逐帧复刻；保留出现/消失淡入淡出
  与选中/悬停状态。
- 编辑器 1152×648 下主屏会被 Godot 左右 Dock 挤压，完整主题页预览请用主题页
  自带的「预览」模式或本页截图；这是编辑器布局限制，不是主题布局溢出。
