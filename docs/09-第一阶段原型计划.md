# 09 · 第一阶段：可运行原型详细计划

> 对应需求文档 §19 第 10 项、§17 第一阶段。
>
> 阶段目标（原文）：完成 EditorPlugin 注册、事件节点与资源、事件编辑面板、基础事件页、开关与变量、条件分歧、显示文字、顺序执行、基础交互触发。
> 验收（原文）：玩家与 NPC 交互，第一次获得钥匙，第二次显示不同台词；不需要手写 NPC 事件脚本。

---

## 1. 范围收口

### 做

- 1 个 Autoload、1 个停靠面板、1 个 Inspector 插件、4 个组件节点。
- 数据模型：`EventDefinition` / `EventPage` / `EventCommand` / `StateCatalog` / `StateDefinition`（+ 引用类型）。
- 指令 10 条：显示文字、显示选项、条件分歧、设置开关、设置变量、变量运算、等待、调用公共事件、播放音效、结束事件。
- 运行时：`EventRunner` + 顺序执行 + 条件/等待 + 取消 + 完成通知。
- 状态：三作用域 + 类型校验 + 通知 + 简单快照。
- 编辑器：事件页管理、指令列表、参数弹窗、撤销重做、手动保存。
- 调试：只读状态列表 + 执行日志 + 条件不满足原因（简版）。

### 不做（推到第二阶段以后）

总控图、剧情演出指令（镜头/移动/淡入淡出）、多事件页优先级可视化、存档、AI、时间轴、2D 视口拾取、状态引用索引的全量分析。

## 6. 测试策略（不引入第三方）

Godot 没有内置测试框架，自建极简 runner：

```
tests/run.gd                 # headless 入口，extends SceneTree（--script 要求 MainLoop 子类）
tests/framework/assert.gd    # assert_eq / assert_true / assert_signal
tests/test_state_store.gd
tests/test_event_runner.gd
tests/test_validator.gd
tests/test_uid_ref.gd
tests/fixtures/*.tres
```

- 运行：`godot --headless --path . --script res://tests/run.gd`
- 退出码非 0 表示失败，可直接进 CI。
- 运行时测试不依赖真实场景：用 `MockPresenter` + `MockAdapter`，验证指令流与状态变化。

## 7. 演示场景设计（M4）

```
school_demo.tscn
├── Player (CharacterBody2D)          # 组: player；有 interact 动作
├── NPC_Librarian (Node2D + Sprite2D)
│    └── EventInteractor2D            # event_ref = librarian.tres
├── KeyPickup (Area2D + Sprite2D)
│    ├── EventInteractor2D            # 第一次交互给钥匙
│    └── CollisionShape2D
└── UI (CanvasLayer)                  # 插件提供的 dialogue_box 由运行时自动挂载
```

`librarian.tres` 两页：

| 页 | 条件 | 指令 |
| --- | --- | --- |
| 1 | （无条件，兜底） | 显示文字「你看起来在找什么？」→ 显示选项「询问钥匙/离开」→ 询问分支：设置开关 `Global.Player.HasKey = true`、显示「这把钥匙给你。」 |
| 2 | `Global.Player.HasKey == true` | 显示文字「钥匙要收好，教室门就在右边。」 |

**页序陷阱**：规则是「取序号最大且条件满足的页」，所以**兜底页必须放最前面**，条件页放后面。
若把无条件页放到最后，它将永远胜出，条件页永远不生效——这是 RPG Maker 式事件最容易配错的地方，编辑器里页签从左到右就是优先级从低到高。

## 8. 第一阶段明确规避的技术坑

| 坑 | 规避 |
| --- | --- |
| `@tool` 脚本在编辑器里访问 `SceneTree` | 编辑器 UI 只用 `EditorInterface`，不假设有游戏循环 |
| Resource 改动不触发保存 | 统一 `EventDocument.mark_dirty()`，监听 `resource_saved` |
| 撤销栈串味（场景撤销里出现事件操作） | 所有事件编辑用 `custom_context = document` |
| `NodePath` 存绝对路径 | 只存 owner 相对路径 + 唯一名 |
| 中文标点在 UI 中被截断 | 固定最小宽 + `clip_text = false`，字体走编辑器默认 |
| `await` 后节点已释放 | 所有 await 前记 `instance_id`，返回后校验 |
