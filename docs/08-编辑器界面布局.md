# 08 · 编辑器界面布局

> 对应需求文档 §19 第 9 项、§11。

---

## 1. 总体形态

插件在 Godot 编辑器里提供**两种入口**，共用数据与撤销栈：

```
入口 A：2D 视口选中事件对象 → 右下角停靠面板「事件」
入口 B：主编辑屏「Event Studio」→ 关卡总控图 + 事件列表 + 调试
```

```
┌─ 主编辑屏 [Event Studio] ─────────────────────────────────────────────┐
│ ┌─左栏 260px─┐ ┌──────────── 工作区 ────────────┐ ┌─右栏 280px─┐ │
│ │ 关卡        │ │  ┌ 标签页 ─────────────────┐ │ │ 状态检查器  │ │
│ │  ▸ school   │ │  │ [总控图] [事件:管理员]  │ │ │ 分类折叠    │ │
│ │   ▸ 阶段     │ │  ├─────────────────────────┤ │ │ 搜索        │ │
│ │   ▸ 事件     │ │  │                         │ │ │ 值编辑      │ │
│ │   ▸ 公共事件 │ │  │   GraphEdit / 事件列表   │ │ │ 引用跳转    │ │
│ │   ▸ 状态     │ │  │                         │ │ └────────────┘ │
│ └────────────┘ │  └─────────────────────────┘ │                │
│                │ ┌─ 底部：指令列表 / 日志 ────┐ │                │
│                │ └─────────────────────────┘ │                │
└──────────────────────────────────────────────────────────────────┘
```

- 主屏实现方式：`EditorPlugin._has_main_screen() = true` + `_make_visible()`；主屏按钮显示在 "2D / 3D / Script" 旁边。
- 若用户不需要主屏，可关闭主屏（设置项），全部功能退化为停靠面板（适合小工程）。

## 2. 停靠面板（4.7 `EditorDock`）

| Dock | 标题 | 默认槽位 | 内容 | 可关闭 |
| --- | --- | --- | --- | --- |
| dock_event | 事件 | `RIGHT_UL` | 选中事件节点/资源的事件页编辑器（紧凑模式） | 否 |
| dock_state | 状态 | `RIGHT_BL` | 状态监视器（运行时可编辑） | 是 |
| dock_log | 事件日志 | `BOTTOM_L` | 执行日志、耗时、触发来源、错误 | 是 |
| dock_events_palette | 指令搜索 | `BOTTOM_R` | 可拖拽的指令面板（Ctrl+Space 唤起） | 是 |

4.7 的 `EditorDock` 支持 `available_layouts`（垂直/水平/浮动）与 `layout_key`（布局持久化），用户的停靠位置会被记住。

### 3.1 指令列表控件

| 交互 | 行为 |
| --- | --- |
| 单行点击 | 选中；右侧/下方出现内联参数摘要，双击打开参数弹窗 |
| 拖拽 | 重排；拖到块内（条件/循环）时显示插入指示线 |
| 多选 | Ctrl 点选、Shift 连选；批量删除/复制/启停 |
| 折叠 | 条件分歧/循环块左侧三角 |
| 缩进 | 由数据 `children` 决定，非手工缩进；Tab/Shift+Tab 调整层级（会移动数据到兄弟块） |
| 右键 | 插入上方/下方、复制、粘贴、剪切、禁用、加注释、上下移动 |
| Ctrl+Z / Ctrl+Y | 走 `EditorUndoRedoManager`，`custom_context = EventDocument` |

**渲染方式**：虚拟滚动 `ItemList` + 每行一个自绘 `Control`（图标 + 缩进线 + 指令名 + 参数摘要）。避免 `Tree`（4.7 的 Tree 不支持行内自定义控件）。每行高度 24px，超过 800 行只渲染可视区 ±20。

### 3.2 指令参数弹窗

按 `CommandSpec.param_schema` 自动生成，规则：

| 参数类型 | 控件 |
| --- | --- |
| `string` | LineEdit（多行用 TextEdit） |
| `int` / `float` | SpinBox |
| `bool` | CheckBox |
| `enum` | OptionButton |
| `state_key` | `StatePickerButton`（按作用域/分类过滤 + 类型过滤 + 搜索 + 最近使用） |
| `event_ref` | `EventPickerButton`（列出工程内事件/公共事件，显示标签与所属关卡） |
| `node_ref` | `SceneNodePickerButton`（点按钮后在 2D 视口拾取，或从树里选） |
| `resource` | EditorResourcePicker（带类型过滤） |
| `path_points` | PathPointsEditor（可视路径，见 §7） |
| `commands` | 嵌套指令列表（条件/循环体） |

**约束：尽量不出现裸输入框**。凡是"名字/路径/引用"，一律用选择器（需求 §11.3）。

## 4. 事件页条件编辑

条件行：`[状态 ▾] [比较 ▾] [值]`，多条之间 `AND`；点 `AND ▾` 可换 `OR`（内部转成条件树，UI 上用缩进表达）。

- 支持语义条件：`持有道具`、`任务状态`、`关卡阶段`、`自定义条件（已注册的 ConditionProvider）`。
- 条件行可拖到任意位置；"复制条件到其他事件页"是常见需求，支持 Ctrl+C/V。

## 5. 关卡总控图（主屏）

```
┌ 工具栏 ────────────────────────────────────────────────┐
│ [+节点▾] [分组] [自动布局] [校验] [运行高亮:ON] [搜索]  │
├────────────────────────────────────────────────────────┤
│  ┌─ GraphFrame: 第一幕 进入学校 ─────────────────────┐  │
│  │  ┌─开始──────┐      ┌─阶段:探索─────┐            │  │
│  │  │ 关卡开始   ├─────►│ 开放办公室/教室│            │  │
│  │  └───────────┘      └───────┬───────┘            │  │
│  │                     ┌───────┴────────┐            │  │
│  │              ┌──────▼──────┐  ┌──────▼──────┐      │  │
│  │              │ 事件:办公室 │  │ 事件:教室   │      │  │
│  │              └──────┬──────┘  └──────┬──────┘      │  │
│  │                     │                │             │  │
│  │                ┌────▼────────────────▼───┐         │  │
│  │                │ AND: 两个线索都完成     │         │  │
│  │                └────────────┬───────────┘         │  │
│  └─────────────────────────────┼─────────────────────┘  │
│                        ┌───────▼────────┐               │
│                        │ 动作:解锁地下室 │  ✓ 已完成     │
│                        └───────┬────────┘               │
└────────────────────────────────┴────────────────────────┘
```

| 功能 | 实现 |
| --- | --- |
| 节点拖动/连线/缩放/平移 | GraphEdit 原生 |
| 分组 | `GraphFrame` + `graph_elements_linked_to_frame_request` |
| 搜索定位 | 顶部搜索框，匹配标题/参数/事件名，命中后居中 |
| 复制粘贴 | `copy_nodes_request` / `paste_nodes_request`，内部序列化为子图字典 |
| 运行高亮 | 订阅 `GraphRuntimeState`，节点标题栏状态灯（灰/蓝闪/绿/红） |
| 当前阶段 | 当前 `stage` 节点加粗边框 + 顶部面包屑显示 `school › chase` |
| 状态依赖 | 选中节点时，所有读写相关状态的行高亮（可关） |
| 校验 | 工具栏「校验」跑 `GraphLinter`，问题列表双击定位 |
| 小地图 | GraphEdit 内置 minimap（4.7 有），默认开 |

## 7. 2D 视口增强（`_forward_canvas_draw_over_viewport`）

| 叠加 | 显示条件 | 内容 |
| --- | --- | --- |
| 事件标记 | 总开关开 | 挂在节点上画小徽标（事件 id + 页数） |
| 触发区域 | 选中事件 | 半透明矩形 + 触发方式颜色 |
| 移动路径 | 选中含移动指令的事件 | 折线 + 控制点 + 箭头 + 速度标注 |
| 交互范围 | 选中事件 | 圆形范围 |
| 引用高亮 | 从图里点"在场景中定位" | 闪烁 1.2 秒 |

路径编辑器：在视口里点击加点、拖拽调整、右键删点、`Enter` 确认 → 写入 `params.path`（点数组 + 速度 + 是否等待）。

## 8. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做（按上下文：事件 / 图 / 状态） |
| `Ctrl+F` | 指令搜索（事件编辑器内） |
| `Ctrl+Space` | 指令面板（可拖拽插入） |
| `F2` | 打开选中节点的事件编辑器 |
| `Ctrl+Shift+P` | 命令面板（集成 `EditorInterface.get_command_palette()`） |
| `Ctrl+D` | 复制选中指令/节点 |
| `Delete` | 删除选中 |
| `Alt+↑/↓` | 指令上移/下移 |
| `Tab` / `Shift+Tab` | 指令缩进/反缩进 |
| `Ctrl+Enter` | 从当前事件开始试跑（预览） |
| `F6` | 运行当前场景（含插件运行时的真实演出） |

## 9. 中文与主题

- 源字符串中文 + `tr()`；`editor/i18n/rpg_event_studio.zh_CN.csv`（源）+ `en.csv`（预留）。
- 图标：`editor/themes/icons/`，16×16 SVG，命名 `cmd_<id>.svg`；缺图标的指令用分类默认图标。
- 颜色使用 `EditorInterface.get_editor_theme()` 的 `dark_color_*`/`accent_color`，**不硬编码色值**，保证亮色主题可用。
