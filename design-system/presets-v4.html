一、游戏化要素（所有预设通用，可逐项开关）

  1. 11大立绘位：立绘压在面板后方并出框（替代原来面板内的小头像框；小头像模式保留为选项）。
  2. 12键帽提示：A / 空格 / 1-2-3 用几何键帽绘制，随输入设备切换（已有 InputService 可提供）。
  3. 13推进指示：三角 / 菱形 / 圆点 / 光标块——全是几何图形，不是字符。
  4. 14选项光标：选中项前的三角/菱形/指示条，或整行位移+硬投影。
